# 演習04: 配列操作

## この演習で学ぶこと

- 添字配列(インデックス配列)と連想配列の違いを理解する
- `array_map` / `array_filter` / `array_reduce` を使って配列を加工できるようになる
- `sort` 系関数(`sort`, `asort`, `usort`)で配列を並び替えられるようになる
- 配列の中に配列が入った「多次元配列」を扱えるようになる

## 前提知識

- 演習03(繰り返し処理)の内容を理解していること
  - `for` / `foreach` などの繰り返し構文
  - 配列の要素を1つずつ処理する方法
- 演習01・02で学んだ変数、データ型、条件分岐の基本

## 演習内容(要件)

サーバーの監視ダッシュボードを作るイメージで、複数台のサーバー情報を配列で扱います。

### 1. サーバー情報の多次元配列を作る

「サーバー名(`name`)」「CPU使用率(`cpu`)」「メモリ使用率(`memory`)」を持つ
連想配列を1台分のサーバー情報とし、それを4〜5台分集めた**多次元配列**を作ってください。

```php
$servers = [
    ["name" => "web01", "cpu" => 85, "memory" => 60],
    ["name" => "web02", "cpu" => 45, "memory" => 70],
    // ... あと2〜3台分
];
```

### 2. CPU使用率が高い順に並び替える

`usort()` を使って、`$servers` を **CPU使用率が高い順(降順)** に並び替えてください。

### 3. CPU使用率が80%以上のサーバーだけを抽出する

`array_filter()` を使って、CPU使用率が80%以上のサーバーだけを抽出した新しい配列を作ってください。

### 4. 表示用の文字列一覧を作る

`array_map()` を使って、各サーバーの情報を `"web01: CPU 85%"` のような
表示用の文字列に変換した配列を作ってください。

### 5. 平均CPU使用率を計算する

`array_reduce()` を使って、全サーバーのCPU使用率の平均値を計算してください。

### (おまけ)サーバー名でも並び替えてみる

`asort()` を使って、サーバー名だけを集めた配列をアルファベット順に並び替える処理も
`answer.php` の中で紹介しています。余裕があれば `practice.php` でも試してみましょう。

## ヒント

- 連想配列はキーと値のペアで、キーは文字列でも数値でも指定できます。
  `["name" => "web01", "cpu" => 85]` のように、キーには意味のある名前を付けられるので、
  「何番目の要素か」ではなく「何の値か」でアクセスできて読みやすくなります。
- `usort()` のコールバック関数は、「マイナスなら前、プラスなら後ろ」という
  比較結果(負の数・正の数・0)を返す必要があります。
  例えば `$b["cpu"] - $a["cpu"]` を返すと、`$a` より `$b` のCPU使用率が高いときに
  正の数になり、`$a` が後ろに回る(=CPU使用率が高い順に並ぶ)ことになります。
- `array_filter()` は「条件に合う要素だけ残す」、`array_map()` は「全要素を変換する」、
  `array_reduce()` は「全要素を1つの値にまとめる」と覚えると区別しやすいです。
- `array_filter()` で要素を取り除くと、配列のキー(添字)が飛び飛びになります。
  連番に振り直したい場合は `array_values()` を組み合わせると便利です。
- `array_reduce()` の第3引数(初期値)を忘れると、配列が空のときにエラーの原因になることがあります。

## サーバーエンジニアとの関連

監視データの集計・フィルタリング・並び替えは、サーバー監視ダッシュボードの裏側で
必ず行われている配列操作そのものです。

- 実際の監視ツール(Zabbix、Mackerel、Datadogなど)では、多数のサーバーから
  CPUやメモリの使用率といった数値を定期的に集めています。その内部データは、
  今回作った `$servers` のような「連想配列の配列(多次元配列)」で表現されることが
  非常によくあります。
- ダッシュボード画面で「負荷が高い順にサーバーを並べたい」という要望は、
  この演習で使った `usort()` による並び替えそのものです。
- 「しきい値を超えたサーバーだけを一覧表示したい」「アラートを出したい」といった
  機能は、`array_filter()` のような「条件で絞り込む」処理の応用です。
- 「全サーバーの平均負荷を出したい」「合計値を知りたい」といった集計処理は、
  `array_reduce()` のような「複数の値を1つにまとめる」処理の応用です。

配列を自在に操作できるようになると、監視データや設定ファイルなど、
サーバー構築の現場で扱う様々なデータをプログラムで処理できるようになります。

## 発展課題

余裕がある人は、以下にも挑戦してみましょう。

- メモリ使用率(`memory`)についても、CPU使用率と同じように
  「高い順に並び替える」「80%以上を抽出する」処理を追加で書いてみましょう。
  また、CPU使用率とメモリ使用率の**両方**が80%以上のサーバーだけを
  `array_filter()` で抽出する処理にも挑戦してみましょう
  (コールバック関数の中で `&&` を使って2つの条件をつなげます)。
