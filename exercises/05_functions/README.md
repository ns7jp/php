# 演習05: 関数の作成

## この演習で学ぶこと

- 関数の定義方法(引数・戻り値)を理解する
- 引数のデフォルト値と型宣言(型ヒント)を使えるようになる
- 可変長引数(`...`)とスコープ(変数の有効範囲)を理解する
- 無名関数・アロー関数(`fn`)の基本を理解する

## 前提知識

- 演習04(配列操作)の内容を理解していること
  - 配列の基本(添字配列・連想配列)
  - `array_map()` など、配列を加工する関数の使い方
  - `foreach` で配列を1つずつ処理する方法
- 演習01〜03で学んだ変数、データ型、条件分岐、繰り返し処理の基本

## 演習内容(要件)

サーバー構築・運用の現場で実際によく使われる処理を、自分で定義した「関数」として
作ってみましょう。今回は大きく4つのテーマに取り組みます。

### 1. `formatBytes()` 関数を作る(デフォルト引数・型宣言)

バイト数(`int`)を受け取り、`"1.5 KB"` や `"5 GB"` のように、人間が読みやすい
単位の文字列(`string`)に変換する関数を作ります。

```php
function formatBytes(int $bytes, int $precision = 2): string
```

- 第1引数 `$bytes` はバイト数(`int` 型)
- 第2引数 `$precision` は小数点以下の桁数で、**デフォルト値として `2`** を持たせます
  (呼び出し時に省略したら `2` 桁で丸められるようにする)
- 戻り値の型は `string` として宣言します
- 1024ごとに `B → KB → MB → GB → TB` と単位を繰り上げて変換します

### 2. `listServers()` 関数を作る(可変長引数)

サーバー名を**いくつでも**受け取り、`"監視対象: web01, web02, db01"` のように
まとめて表示する関数を作ります。

```php
function listServers(string ...$names): void
```

- `...$names` の部分が「可変長引数」で、引数の数を決めずに、いくつでも
  文字列を渡せるようにする書き方です
- 関数の中では `$names` が配列として扱えます

### 3. 変数のスコープ(有効範囲)を確認する

関数の外で定義した変数が、関数の中からはそのままでは見えないことを確認し、
「引数として渡す」ことで正しく値を受け渡す方法を体験します。

### 4. 無名関数・アロー関数(`fn`)を比較する

配列内の数値を2倍にするだけの、次の2つの関数を書きます。

- 無名関数(`function ($n) { ... }` の形)
- アロー関数(`fn($n) => ...` の形)

どちらも `array_map()` に渡して、同じ結果になることを確認します。

## ヒント

- 関数の外で定義した変数は、そのままでは関数の中から見えません(スコープが違うためです)。
  関数の中でどうしても外の値を使いたいときは、**引数として渡す**のが基本の考え方です。
- デフォルト引数(例: `int $precision = 2`)は、呼び出し時にその引数が省略された場合に
  使われる値です。`formatBytes(1536)` のように呼び出せば `$precision` は自動で `2` になります。
- 型宣言(`int $bytes` や `: string` の部分)を書いておくと、意図しない型の値が
  渡されたときにPHPがエラーとして教えてくれるため、バグに早く気づけます。
- 可変長引数 `...$names` を使った関数は、`listServers('web01')` のように1つだけ渡しても、
  `listServers('web01', 'web02', 'db01')` のように何個渡しても、`listServers()` のように
  0個で呼び出してもエラーになりません(関数の中では常に配列として扱われます)。
- アロー関数 `fn(...) => ...` は、無名関数と違って `use ($変数名)` と書かなくても、
  外側にある変数を自動的に取り込める短縮記法です。1行で書けるシンプルな処理に向いています。
- `log($bytes, 1024)` を使うと「1024で何回割れるか(=どの単位を使うべきか)」を
  計算できます。`floor()` で整数に切り捨てて使いましょう。

## サーバーエンジニアとの関連

`formatBytes()` は、ディスクやメモリの空き容量を表示する際に**必ずと言っていいほど
使われる、実務でも定番の自作関数**です。

- OSやプログラムが扱う容量は、内部的には常にバイト単位(数値)で管理されています。
  しかし、人間にとって `5368709120` という数字よりも `"5 GB"` という表示のほうが
  はるかに理解しやすいため、多くのサーバー管理画面・監視ツール・`ls -lh` や
  `du -h` のようなLinuxコマンドが、内部では今回作ったのと似た変換処理を行っています。
- ディスク使用量のアラート(「空き容量が1GBを切ったら通知する」など)を実装するときも、
  「しきい値との比較」は生のバイト数のまま行い、「画面に表示するとき」だけ
  `formatBytes()` のような関数を通す、という役割分担がよく使われます。
- `listServers()` のように「対象を可変長引数でまとめて受け取り、一覧として表示する」
  処理は、監視対象サーバーの一覧表示や、コマンドライン引数を受け取るスクリプトなど、
  台数や個数が決まっていない状況を扱う場面で頻繁に登場します。
- 関数として処理をまとめておくことで、同じ変換ロジックをディスク容量表示・
  メモリ使用量表示・ネットワーク転送量表示など、複数の画面や機能から
  **使い回せる**ようになります。これは実務のコードで非常に重視される考え方です。

## 発展課題

余裕がある人は、以下にも挑戦してみましょう。

- 複数のファイルサイズを可変長引数で受け取り、その合計バイト数を返す
  `sumBytes(int ...$sizes): int` という関数を作ってみましょう。
  そして `formatBytes(sumBytes(1048576, 2097152, 524288))` のように、
  今回作った2つの関数(可変長引数の関数と `formatBytes()`)を**組み合わせて**、
  「複数ファイルの合計サイズを読みやすい単位で表示する」処理を書いてみましょう。
