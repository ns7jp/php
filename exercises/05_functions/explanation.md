# 解説: 関数の作成

## コードの流れ

`answer.php` は大きく4つのパートに分かれています。

1. **`formatBytes()` 関数を作る(デフォルト引数・型宣言)**
   バイト数(`int`)を受け取り、`1024` ごとに単位を繰り上げながら
   `"1.5 KB"` のような読みやすい文字列(`string`)に変換する関数です。
   第2引数 `$precision` にはデフォルト値 `2` を持たせているので、
   省略して呼び出すと小数点以下2桁で丸められます。

2. **`listServers()` 関数を作る(可変長引数)**
   `string ...$names` という可変長引数を使い、サーバー名をいくつ渡しても
   受け取れる関数です。受け取った名前を `implode()` でつなげて
   `"監視対象: web01, web02, db01"` のように表示します。

3. **変数のスコープ(有効範囲)を確認する**
   関数の外(グローバルスコープ)で定義した `$serviceName` が、
   そのままでは関数の中から見えないことを `isset()` で確認したあと、
   「引数として渡す」ことで正しく値を受け渡す方法を紹介しています。

4. **無名関数とアロー関数(`fn`)を比較する**
   「数値を2倍にする」という同じ処理を、無名関数(`function`)と
   アロー関数(`fn`)の両方で書き、`array_map()` に渡した結果が
   完全に一致することを確認しています。

全体を通して、「同じ処理を毎回書き直すのではなく、名前を付けてまとめておき、
必要なときに呼び出す」という関数の基本的な考え方と、関数どうしの
「境界線」(スコープ)の存在を体験できる構成になっています。

## 重要なポイント(使用した関数・構文の解説)

- **関数の定義(引数・戻り値)**
  `function 関数名(引数) { 処理; return 戻り値; }` の形で関数を定義します。
  引数は関数の中でだけ使える「その関数専用の変数」になり、`return` で
  呼び出し元に値を返すことができます(`return` を書かない、または
  `void` 型の関数は値を返さず、処理を行うだけになります)。

- **デフォルト引数**
  `function formatBytes(int $bytes, int $precision = 2)` のように、
  引数に `= 値` を付けると、その引数を省略して呼び出したときに
  自動でその値が使われます。`formatBytes(1536)` と呼び出すと、
  `$precision` には `2` が入ります。

- **型宣言(型ヒント)**
  `int $bytes` のように引数の前に型名を書くと、その引数に渡せる値の型を
  制限できます。同様に `function ...(): string` のように関数名の後ろに
  `:型名` を書くと、戻り値の型を宣言できます。意図しない型の値が
  渡された(または返された)場合、PHPが `TypeError` として教えてくれるため、
  バグに早く気づけるようになります。

- **可変長引数(`...`)**
  `string ...$names` のように型名の後ろに `...` を付けて宣言すると、
  その引数はいくつでも(0個でも)受け取れるようになります。関数の中では
  `$names` はふつうの配列として扱えるので、`count()` や `foreach`、
  `implode()` などをそのまま使えます。

- **スコープ(変数の有効範囲)**
  PHPの関数は、それぞれが独立した「スコープ」を持ちます。関数の外
  (グローバルスコープ)で定義した変数は、そのままでは関数の中から
  見えません。これは「うっかり関数の外の変数を書き換えてしまう」といった
  事故を防ぐための仕組みです。関数の中で外の値を使いたいときは、
  引数として明示的に渡すのが基本の方法です。

- **無名関数(匿名関数)**
  `function ($n) { return $n * 2; }` のように、名前を付けずにその場で
  作る関数です。変数に代入したり、`array_map()` のように「関数そのものを
  渡す必要がある場所」で使います。外側の変数を使いたいときは、
  `use ($変数名)` を書いて明示的に取り込む必要があります。

- **アロー関数(`fn`)**
  `fn ($n) => $n * 2` のように、無名関数をさらに短く書ける記法です。
  `return` を省略でき、式の結果がそのまま戻り値になります。
  無名関数と大きく違う点として、`use()` を書かなくても外側の変数を
  自動的に取り込んで使うことができます。ただし1つの式しか書けないため、
  複数行にわたる複雑な処理には向いていません。

- **`array_map($callback, $array)`**
  配列の全要素に対してコールバック関数(無名関数やアロー関数など)を
  適用し、変換後の値をまとめた新しい配列を返す関数です。今回は
  「数値を2倍にする」処理を無名関数版・アロー関数版それぞれで渡し、
  結果を比較しています。

- **`implode($区切り文字, $array)`**
  配列の要素を指定した文字でつなげて、1つの文字列にする関数です。
  `implode(', ', ['web01', 'web02'])` は `"web01, web02"` になります。

## 初心者がつまずきやすいポイント

- **デフォルト引数の位置**
  デフォルト値を持つ引数は、デフォルト値を持たない引数より
  **後ろ**に書く必要があります。`function f($a = 1, $b)` のような順番は
  エラーになります(`formatBytes(int $bytes, int $precision = 2)` のように、
  必須の引数を先、省略可能な引数をあとに書きます)。

- **無名関数とアロー関数での「外側の変数の扱い方」の違い**
  無名関数は `use ($変数名)` を書かないと外側の変数を使えませんが、
  アロー関数は何も書かなくても自動的に使えます。この違いを覚えていないと、
  「無名関数の中で外の変数がなぜか使えない(未定義になる)」という
  つまずきにつながります。

- **可変長引数は「必ず最後」に書く**
  可変長引数(`...$names`)は、関数の引数リストの一番最後に置く必要が
  あります。`function f(...$names, $last)` のような書き方はエラーになります。
  複数の通常引数のあとに可変長引数を1つだけ置く、という形が基本です。

- **「関数の外の変数が見えない」ことへの戸惑い**
  変数のスコープという考え方に初めて触れると、「さっき定義したはずの
  変数が、関数の中だと使えない」ことに戸惑うかもしれません。これは
  バグではなく、PHP(に限らず多くのプログラミング言語)が意図的に
  持たせている安全な仕組みです。関数は「渡された引数だけを頼りに動く
  部品」として作ると、あとから読んでも動きが予測しやすくなります。

- **`return` と `echo` の違い**
  `return` は「呼び出し元に値を返す」ためのもので、画面には何も
  表示されません。`echo` は「画面に文字を表示する」ためのものです。
  `formatBytes()` は `return` で文字列を返す関数、`listServers()` は
  `echo` で直接表示する関数、という役割の違いを意識しておくと、
  「なぜこの関数は `echo` を使うのに、こっちは `return` なのか」が
  理解しやすくなります。

## よくあるエラーと対処法

- **`Fatal error: Cannot use positional argument after default argument`**
  デフォルト値を持たない引数を、デフォルト値を持つ引数より後ろに
  書いてしまったときに出るエラーです。`function f($a = 1, $b)` を
  `function f($b, $a = 1)` のように、必須の引数を先に書く順番へ
  直しましょう。

- **`TypeError: formatBytes(): Argument #1 ($bytes) must be of type int, string given`**
  型宣言(`int $bytes` など)で指定した型と違う型の値を渡したときに
  出るエラーです。例えば `formatBytes("1000")` のように文字列を
  渡すと発生することがあります(ただし `"1000"` のような数値として
  解釈できる文字列は、PHPの設定によっては自動変換されて動くことも
  あります)。呼び出し元で渡している値の型を確認しましょう。

- **`Warning: Undefined variable $変数名`**
  関数の中で、関数の外の変数(または存在しない変数)をそのまま
  使おうとしたときに出る警告です。今回の演習の
  `showServiceNameBroken()` のように、意図的にこの状況を作って
  スコープを学ぶこともありますが、実際のコードでは「変数を
  引数として渡す」ことで防ぐのが基本です。

- **`Fatal error: Uncaught Error: Too few arguments to function listServers(), 0 passed`**
  可変長引数ではない、ふつうの必須引数を持つ関数に対して、
  引数を渡さずに呼び出してしまったときに出るエラーです。
  可変長引数(`...$names`)を使っている関数は0個の引数でも
  呼び出せますが、通常の引数(デフォルト値なし)は省略できない
  ことを覚えておきましょう。

- **アロー関数の中で複数の処理をしようとしてエラーになる**
  アロー関数(`fn`)は「1つの式」しか書けません。
  `fn($n) => { echo $n; return $n * 2; }` のように `{}` を使った
  複数行の処理を書くとエラーになります。複数の処理が必要な場合は、
  素直に無名関数(`function ($n) { ... }`)を使いましょう。

## まとめ

- 関数は「引数を受け取り、処理をして、戻り値を返す(または画面に表示する)」
  ひとまとまりの部品です。同じ処理を何度も書く代わりに、関数として
  まとめておくことで、コードが読みやすく、再利用しやすくなります。
- デフォルト引数を使うと、「よく使う値」を省略できるようになり、
  関数の呼び出し側のコードをシンプルに保てます。
- 型宣言(型ヒント)を書いておくと、意図しない型の値が紛れ込んだときに
  PHPがエラーとして教えてくれるため、バグの早期発見につながります。
- 可変長引数(`...`)を使うと、「いくつ渡されるかわからないもの」を
  自然に扱える関数を作れます。
- 変数にはスコープ(有効範囲)があり、関数の外の変数は関数の中から
  そのままでは見えません。関数の中で使いたい値は、引数として
  明示的に渡すのが基本です。
- 無名関数とアロー関数は、どちらも「その場で作る、名前のない関数」です。
  アロー関数は短く書けて外側の変数を自動的に取り込めますが、
  1つの式しか書けないという制約もあります。処理の複雑さに応じて
  使い分けられるようになりましょう。
- 今回作った `formatBytes()` や `listServers()` のような関数は、
  サーバーの状態を人間にわかりやすく表示するための「部品」として、
  実務のコードでもそのままの考え方で使われています。
