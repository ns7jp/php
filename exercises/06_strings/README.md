# 演習06: 文字列操作

## この演習で学ぶこと

- 文字列連結と `sprintf` / `printf` を使った整形出力ができるようになる
- `trim`、`str_replace`、`explode`、`implode` を使って文字列を加工できるようになる
- `preg_match` を使った正規表現によるパターンマッチの基礎を理解する
- 「単純な分割」と「正規表現によるパターンマッチ」を使い分けられるようになる

## 前提知識

- 演習05(関数の作成)の内容を理解していること
  - 独自の関数を定義して処理をまとめる方法
  - 関数の引数・戻り値の考え方
- 演習01〜04で学んだ変数、データ型、条件分岐、配列の基本
  - 特に配列(`explode` の戻り値は配列になります)

## 演習内容(要件)

サーバーのログファイルには、次のような形式の行がよく登場します。

```
2024-01-15 10:23:45 [ERROR] Disk full on server01
```

この1行の文字列から「日付」「時刻」「レベル(ERRORなど)」「メッセージ」を
取り出す処理を、**2つの方法**で実装して比較します。

### 1. `explode()` を使って分割する

ログの1行を表す文字列を用意し、`explode(" ", $line)` を使って
半角スペース区切りで分割してください。分割した結果から、

- 1番目の要素 → 日付
- 2番目の要素 → 時刻
- 3番目の要素 → レベル(`[ERROR]` のように `[` `]` が付いた状態)
- 4番目以降の要素 → メッセージ(複数の単語に分かれてしまう点に注意)

を取り出してください。レベルの `[` `]` は `str_replace()` や `trim()` を
使って取り除き、メッセージ部分は `implode(" ", ...)` で1つの文字列に
戻してください。

### 2. `preg_match()` を使って一度に取り出す

正規表現 `'/^(\S+) (\S+) \[(\w+)\] (.+)$/'` を使い、`preg_match()` で
日時・レベル・メッセージを**一度に**取り出してください。
マッチした結果は `$matches` のような配列に格納され、

- `$matches[1]` → 日付
- `$matches[2]` → 時刻
- `$matches[3]` → レベル
- `$matches[4]` → メッセージ

のように取得できます。

### 3. 2つの方法の結果を比較する

`explode()` で取り出した結果と `preg_match()` で取り出した結果が
同じ内容になっているかを比較し、画面に分かりやすく表示してください。

### 4. `sprintf()` で見やすい形式に整形する

取り出した値を `sprintf()` を使って、次のような見やすい形式の文字列に
整形して出力してください。

```
[ERROR] 2024-01-15 10:23:45 - Disk full on server01
```

## 実行方法

ターミナル(コマンドライン)で、この演習のディレクトリに移動してから
以下のコマンドを実行してください。

```bash
# 未完成のひな形を実行してみる(エラーにはならず、TODO部分だけ「まだ実装されていません」と表示されます)
php practice.php

# 模範解答を実行する
php answer.php
```

`practice.php` の中の `// TODO:` と書かれた部分を自分で実装してから、
もう一度 `php practice.php` を実行し、`answer.php` と同じような結果が出るか
確認してみましょう。

構文だけを素早く確認したいときは、次のコマンドも便利です。

```bash
php -l practice.php
```

## ヒント

- `explode()` は単純な区切り文字での分割に向いていますが、
  パターンが複雑な場合は正規表現(`preg_match`)が便利です。
  今回のログのように「メッセージの中にもスペースが含まれる」場合、
  `explode(" ", ...)` だけでは綺麗に分割しきれない点に注目してみましょう。
- 正規表現の `\S+` は「空白以外の文字の連続」、`\w+` は
  「英数字とアンダースコアの連続」を意味します。
  `\S` は Space(空白)ではないものという意味、`\w` は Word(単語)を
  構成する文字という意味だと覚えると理解しやすいです。
- `sprintf()` の `%s` は文字列、`%d` は整数のプレースホルダーです。
  `sprintf("[%s] %s %s - %s", $level, $date, $time, $message)` のように、
  書式文字列の中の `%s` の位置に、後ろに続く引数が順番に当てはめられます。
- `preg_match()` は「マッチしたら1、しなかったら0、エラー時はfalse」を
  返します。`if (preg_match(...))` のように条件式でそのまま使えます。
- 正規表現の中で `[` や `]` のような特殊な意味を持つ記号をそのまま
  文字として使いたいときは、`\[` `\]` のようにバックスラッシュで
  エスケープします。

## サーバーエンジニアとの関連

サーバーやアプリケーションのログを解析する作業では、文字列操作と
正規表現が最も頻繁に使われるスキルです。

- Webサーバー(Nginx、Apacheなど)のアクセスログやエラーログ、
  アプリケーションが出力するログファイルは、今回のログ行のように
  「決まったフォーマットのテキスト」であることがほとんどです。
- 障害調査の現場では、大量のログの中から「ERRORレベルの行だけを探す」
  「特定の時間帯のログだけを抜き出す」「エラーメッセージのパターンを
  集計する」といった作業を日常的に行います。これらはまさに
  `explode()` や `preg_match()` によるパターンマッチが活躍する場面です。
- ログの形式は必ずしも単純な区切り文字だけで表現できるとは限らず、
  「日付の形式が微妙に揺れている」「メッセージの中に想定外のスペースが
  含まれる」といったケースでは、正規表現を使ったほうが正確かつ柔軟に
  情報を取り出せます。
- この演習で学んだ考え方は、演習16のログ解析ツールにつながります。
  実際のログファイルを読み込み、行ごとに解析して集計するという
  より実践的な内容に発展していきます。

## 発展課題

余裕がある人は、以下にも挑戦してみましょう。

- ログの行を複数用意した配列(`INFO`、`WARNING`、`ERROR` など
  レベルが異なる行を3〜5行程度)を用意し、`foreach` ですべての行に
  `preg_match()` を適用してください。そのうえで、レベルが `ERROR` の
  行だけを `sprintf()` で整形して一覧表示するプログラムに挑戦してみましょう。
  (演習04で学んだ `array_filter()` を組み合わせるとさらに応用的です)
