# 演習01: 変数とデータ型

## この演習で学ぶこと

- $記号を使ったPHPの変数宣言と命名規則を理解する
- 主要なデータ型(string, int, float, bool, array, null)を理解する
- 型の確認方法(gettype, var_dump)を使えるようになる
- 型変換(キャスト)と定数(define/const)の使い方を理解する

## 前提知識

この演習はPHP学習の最初の演習です。特別な前提知識は必要ありません。
ただし、以下の環境が整っていることを確認してください。

- PHPがインストールされていて、ターミナル(コマンドライン)で `php -v` が実行できること
- テキストエディタでファイルを開いて編集できること

## 演習内容(要件)

以下の内容を満たすPHPスクリプトを作成してください(`practice.php` に実装していきます)。

1. 各データ型(`string`, `int`, `float`, `bool`, `array`, `null`)の変数を、
   最低1つずつ宣言する
2. `gettype()` を使って、それぞれの変数の型名を出力する
3. `var_dump()` を使って、それぞれの変数の型と中身を出力する
4. 文字列と数値を `.`(ドット演算子)でつなげて、1つのメッセージとして出力する
5. `(int)` や `(string)` によるキャストを使って型変換した例を出力する
6. `intval()` / `strval()` を使って型変換した例を出力する
7. `define()` または `const` を使って定数(例: `SERVER_NAME`)を1つ定義し、
   その値を出力する

## ヒント

- PHPは変数の型を宣言しなくてよい「動的型付け言語」です。`$name = "山田";` のように
  値を代入するだけで、PHPが自動的に型を判断してくれます。
- シングルクォート(`'`)とダブルクォート(`"`)では、変数展開の挙動が違います。
  `'$name'` はそのまま `$name` という文字として出力されますが、`"$name"` は
  変数の中身に展開されます。
- `var_dump()` は型と値を同時に確認できるので、デバッグ(不具合調査)にとても便利です。
  「思っていた型と違う」というバグに気づくきっかけになります。
- 文字列連結には `+` ではなく `.`(ドット)を使います。他の言語の経験がある人は
  混同しやすいので注意してください。

## サーバーエンジニアとの関連

サーバー構築の現場では、設定ファイル(`.ini`、`.env`、YAMLなど)や環境変数から
「ポート番号」や「タイムアウト秒数」といった値を読み込むことがよくあります。
しかし、これらの値は多くの場合「文字列」として読み込まれるため、
そのまま数値として計算に使おうとすると意図しない結果になることがあります。

例えば、設定ファイルから読み込んだタイムアウト秒数が `"30"`(文字列)だった場合、
数値として扱いたければ `intval()` や `(int)` キャストで変換する必要があります。
この演習で学ぶ型変換の知識は、後の演習で `getenv()`(環境変数の取得)や
設定ファイルの読み込みを扱う際にそのまま直結する、非常に重要な基礎です。

## 発展課題

余裕がある人は、以下にも挑戦してみましょう。

- `settype()` 関数を使って、変数の型そのものを直接書き換える処理を試してみてください
  (`gettype()` は型を「調べる」関数、`settype()` は型を「変える」関数です)。
  変換前後で `var_dump()` を使い、型が実際に変わったことを確認してみましょう。
