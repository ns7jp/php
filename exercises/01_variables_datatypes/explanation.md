# 解説: 変数とデータ型

## コードの流れ

`answer.php` は、大きく分けて次の7つのステップで処理を進めています。

1. `string`, `int`, `float`, `bool`, `array`, `null` の6種類の型を持つ変数を、
   それぞれ1つずつ宣言する
2. `gettype()` を使って、各変数の「型名」を文字列として取得し、画面に出力する
3. `var_dump()` を使って、各変数の「型」と「値」をまとめて出力する
4. `.`(ドット演算子)を使って、文字列と数値をつなげた1つのメッセージを作る
5. `(int)` / `(string)` というキャスト構文を使って、変数の型を変換する
6. `intval()` / `strval()` という関数を使って、同じように型を変換する
7. `define()` と `const` の2つの方法で定数を定義し、その値を出力する

上から順番に実行するだけの、とてもシンプルな流れになっています。
`if` による条件分岐や `for` によるループはまだ登場しないので、
「PHPのコードは基本的に上から下に順番に実行される」という感覚を
つかむことに集中してください。

## 重要なポイント(使用した関数・構文の解説)

- **`$変数名 = 値;`(変数宣言)**
  PHPでは変数の型を書かずに、`$`記号 + 変数名 に値を代入するだけで
  変数を作ることができます。これを「動的型付け」と呼びます。
  代入された値によって、PHPが自動的に型(string, int, floatなど)を判断します。

- **`gettype($変数)`**
  引数に渡した変数の型名を、文字列(`"string"`, `"integer"`, `"double"`,
  `"boolean"`, `"array"`, `"NULL"` など)で返す関数です。
  ※ float型は `gettype()` では `"double"` と表示される点に注意してください。

- **`var_dump($変数)`**
  変数の「型」「値の長さ(文字列の場合)」「中身」をまとめて表示する関数です。
  配列やオブジェクトのように複雑なデータの中身を確認したいときに特に便利です。
  複数の変数をまとめて `var_dump($a, $b, $c);` のように渡すこともできます。

- **`.`(ドット演算子)**
  文字列同士、または文字列と数値をつなげる(連結する)ための記号です。
  `"ポート " . 8080` のように書くと、数値の8080が自動的に文字列に変換されて
  `"ポート 8080"` という1つの文字列になります。

- **`(int)`, `(string)`, `(float)`, `(bool)` などのキャスト**
  変換したい型を丸カッコで囲んで変数の前に書くことで、その場で型変換を
  行う構文です。「キャスト」と呼びます。
  例: `(int) "8080"` は 整数の `8080` になります。
  小数を `(int)` でキャストすると、小数点以下は四捨五入ではなく
  「切り捨て」される点に注意してください(例: `(int) 9.99` は `9`)。

- **`intval($値)` / `strval($値)`**
  キャストと似た働きをする「関数」です。`intval()` は値を整数に、
  `strval()` は値を文字列に変換します。
  `intval("80px")` のように、数字の後ろに文字が続く場合は、
  先頭から読み取れるところまで(この例では `80`)を数値として変換します。

- **`define('定数名', 値);` / `const 定数名 = 値;`**
  「定数」を定義するための2つの書き方です。定数は一度定義すると、
  プログラムの実行中に値を変更することができません。
  `define()` は関数なので条件分岐の中などでも実行できますが、
  `const` はファイルのトップレベル(またはクラスの中)に書く、
  よりシンプルな書き方です。どちらも定数名の前に `$` は付けません。

## 初心者がつまずきやすいポイント

- **`+` と `.` の混同**
  他のプログラミング言語(JavaScriptなど)では文字列連結に `+` を使うことが
  多いため、PHPでも `+` を使ってしまいがちです。PHPで `+` は「足し算」専用で、
  文字列連結には `.` を使うということをしっかり覚えておきましょう。

- **シングルクォートとダブルクォートの違い**
  `'$name'`(シングルクォート)は文字通り `$name` という文字列として
  扱われ、変数の中身には展開されません。一方、`"$name"`(ダブルクォート)は
  変数の中身に展開されます。意図しない出力になったときは、
  クォートの種類を確認してみましょう。

- **`gettype()` の戻り値の名前**
  `gettype()` はfloat型を `"float"` ではなく `"double"` と返します。
  「あれ、floatのはずなのに違う名前が出た」と戸惑いやすいポイントです。

- **キャストによる情報の欠落**
  `(int) 9.99` のように小数を整数へキャストすると、小数点以下の情報は
  切り捨てられて失われます。四捨五入したい場合は `round()` 関数を
  先に使う必要があります。

## よくあるエラーと対処法

- **`Parse error: syntax error, unexpected...`**
  文の終わりのセミコロン `;` を書き忘れていたり、丸カッコ `()` や
  波カッコ `{}` の対応が取れていないことが原因です。
  エラーメッセージに書かれている行番号の周辺を確認しましょう。
  `php -l ファイル名` を実行すると、実行せずに文法エラーだけを
  素早くチェックできます。

- **`Warning: Undefined variable $xxx`**
  変数名のスペルミス(例: `$serverName` のつもりが `$servername` になっている)
  が原因であることが多いです。PHPは大文字・小文字を区別するので、
  変数名の綴りを1文字ずつ確認しましょう。

- **`Fatal error: Cannot redeclare constant "SERVER_NAME"`**
  同じ名前の定数を2回定義しようとすると発生します。定数は一度定義したら
  変更できないため、`define()` や `const` を同じ名前で複数回書かないように
  注意してください。

- **期待した文字列にならない(数値がそのまま表示されるなど)**
  `.` の代わりに `,` を使っていないか、あるいは `echo` の引数の並びに
  誤りがないかを確認しましょう。`var_dump()` で変数の中身を確認しながら
  デバッグすると原因を見つけやすくなります。

## まとめ

この演習では、PHPの基本である「変数」と「データ型」の扱い方を学びました。
PHPは動的型付け言語なので変数の型を書く必要はありませんが、
`gettype()` や `var_dump()` を使えば、いつでも今の型を確認できます。
また、`(int)` などのキャストや `intval()` / `strval()` を使えば、
文字列と数値を自在に変換できることも確認しました。
最後に学んだ `define()` / `const` による定数は、
「書き換わってほしくない値」を安全に扱うための仕組みです。

次の演習以降では、これらの基礎知識をベースに、演算子や条件分岐、
繰り返し処理といった、より実践的な内容に進んでいきます。
