# 演習08: ファイル読み書き

## この演習で学ぶこと

- `fopen` / `fread`(`fgets`) / `fclose` を使った、ファイル操作の基本的な流れを理解する
- `file_get_contents` / `file_put_contents` を使うと、少ないコードで手軽にファイル操作ができることを知る
- `file_exists` を使ってファイルの存在を事前に確認する習慣を身につける
- key=value 形式の設定ファイルを読み込み、連想配列に変換する処理を自分で実装できるようになる
- `FILE_APPEND` フラグを使って、ファイルにログを「追記」する方法を理解する

## 前提知識

- 演習07(日付・時刻操作)の内容を理解していること
  - `date()` を使った日時の文字列整形(ログに日時を付ける際に使用します)
- 演習01〜06で学んだ変数、条件分岐、配列、関数、文字列操作の基本
  - 特に配列(連想配列)、`explode()`、自作関数の定義方法

## 演習内容(要件)

サーバー運用スクリプトでは、「設定ファイルを読み込んで動作を変える」
「処理内容を記録するためにログを残す」という処理が非常によく登場します。
この演習では、その2つを実際に手を動かして実装します。

この演習フォルダには、あらかじめ次のようなサンプル設定ファイル
`config.txt` が同梱されています。

```
host=localhost
port=8080
timeout=30
```

### 1. `loadConfig()` 関数を作る

以下のシグネチャ(引数・戻り値の型)を持つ関数 `loadConfig()` を
実装してください。

```php
function loadConfig(string $path): array
```

`loadConfig()` は次の流れで処理を行います。

1. `file_exists($path)` を使って、指定されたパスのファイルが
   存在するかどうかを確認する。存在しない場合は空の配列 `[]` を返す。
2. ファイルが存在する場合は、`file()` 関数(または `fopen` + `fgets` の
   組み合わせ)を使って、ファイルの中身を1行ずつ読み込む。
3. 読み込んだ各行を `explode("=", $line, 2)` でキーと値に分割し、
   `$config[$key] = $value` の形で連想配列に格納する。
4. 完成した連想配列を `return` する。

`config.txt` を `loadConfig()` に渡すと、以下のような連想配列が
得られるはずです。

```php
[
    "host" => "localhost",
    "port" => "8080",
    "timeout" => "30",
]
```

### 2. `writeLog()` 関数を作る

以下のシグネチャを持つ簡易ロガー関数 `writeLog()` を実装してください。

```php
function writeLog(string $message): void
```

`writeLog()` は次の流れで処理を行います。

1. 渡された `$message` の先頭に、現在日時(`date('Y-m-d H:i:s')` など)を
   付け加える。
2. `file_put_contents()` の第3引数に `FILE_APPEND` を指定して、
   同じフォルダの `app.log` というファイルに1行分のログとして書き込む
   (追記する)。

`writeLog()` を呼び出すたびに `app.log` の行数が1行ずつ増えていくことを
確認してください。`practice.php` や `answer.php` を何度か実行してみて、
`app.log` の中身がどう変化するか観察してみましょう。

### 3. `fopen` / `fgets` / `fclose` を使った読み込みも試す

`loadConfig()` とは別に、`fopen($path, 'r')` でファイルを開き、
`while (!feof($handle)) { ... }` のループの中で `fgets($handle)` を
使って1行ずつ読み込み、画面に表示する処理も実装してください。
最後に必ず `fclose($handle)` でファイルを閉じてください。

### 4. `file_get_contents()` で手軽に読み込む方法も試す

`file_get_contents($path)` を使うと、ファイルの中身をまるごと
1つの文字列として1行で読み込めます。この方法でも `config.txt` の
中身を読み込み、表示してください。

## 実行方法

ターミナル(コマンドライン)で、この演習のディレクトリに移動してから
以下のコマンドを実行してください。

```bash
cd exercises/08_file_io

# 未完成のひな形を実行してみる(エラーにはならず、TODO部分だけ「まだ実装されていません」と表示されます)
php practice.php

# 模範解答を実行する
php answer.php
```

`practice.php` の中の `// TODO:` と書かれた部分を自分で実装してから、
もう一度 `php practice.php` を実行し、`answer.php` と同じような結果が
出るか確認してみましょう。

構文だけを素早く確認したいときは、次のコマンドも便利です。

```bash
php -l practice.php
```

`answer.php` や、実装を終えた `practice.php` を複数回実行すると、
同じフォルダに `app.log` というファイルが作成され、実行するたびに
中身が増えていくことを確認できます。`cat app.log`(Windowsの場合は
`type app.log`)などで中身を見てみましょう。

## ヒント

- `fopen` などで自分でファイルを開いた場合は、必ず `fclose()` で
  閉じるようにしましょう。`file_get_contents()` や `file()` のような
  関数は内部で自動的にファイルを閉じてくれるため、`fclose()` を
  呼び出す必要はありません。
- `file_put_contents()` に `FILE_APPEND` フラグを付けないと、
  呼び出すたびにファイルの中身がまるごと上書きされてしまいます。
  「ログを積み重ねていきたい」場合は `FILE_APPEND` が必須です。
- 相対パス(`"config.txt"` など)は、`php` コマンドを実行したときの
  カレントディレクトリに依存してしまうため、別の場所から実行すると
  ファイルが見つからなくなることがあります。`__DIR__ . '/config.txt'`
  のように `__DIR__` を使ってパスを組み立てると、どこから実行しても
  安全に動作します。
- `explode("=", $line, 2)` のように第3引数を指定すると、「最初の
  `=` のところで1回だけ分割する」という意味になります。値の中に
  `=` が含まれるケース(例: `url=http://example.com/?a=1`)でも
  安全に分割できます。
- ファイルから読み込んだ1行の末尾には改行コード(`\n` など)が
  残っていることがあります。`trim()` で取り除くか、`file()` の
  第2引数に `FILE_IGNORE_NEW_LINES` を指定すると自動的に除去できます。

## サーバーエンジニアとの関連

設定ファイルの読み込みや、独自ログの出力は、サーバー運用スクリプトを
書くうえで避けて通れない基本パターンです。

- サーバーで動くアプリケーションの多くは、データベースの接続情報や
  APIキーといった設定値を、ソースコードに直接書き込むのではなく、
  `config.txt` や `.env` のような外部ファイルに分けて管理します。
  こうすることで、本番環境と開発環境で設定だけを差し替えたり、
  秘密情報をソースコード管理(Gitなど)から分離したりできます。
  今回作った `loadConfig()` は、そうした仕組みのごく基本形です。
- サーバー運用の現場では、「いつ・何が起きたか」を記録しておく
  ログがなければ、障害が起きたときに原因を調査することができません。
  `writeLog()` のように、`FILE_APPEND` で追記していく簡易ロガーは、
  本格的なログ管理ツールを使う前段階として、どんなスクリプトにも
  組み込める基本テクニックです。
- `file_exists()` によるファイルの存在確認も、実務では頻繁に登場します。
  「設定ファイルが置き忘れられている」「デプロイ時にファイルの
  コピーを忘れた」といったトラブルは実際によく起こるため、
  ファイルを開く前に存在確認をしておくことで、原因の分かりにくい
  警告やエラーを未然に防ぐことができます。
- この演習で学んだファイル操作の基礎は、演習16のログ解析ツールなど、
  実際のファイルを読み書きするより実践的な演習の土台になります。

## 発展課題

余裕がある人は、以下にも挑戦してみましょう。

- `loadConfig()` とは逆の処理を行う `saveConfig(array $config, string $path): bool`
  という関数を自作してみましょう。連想配列を `"host=localhost"` の
  ような文字列の並びに変換し(`implode()` や `foreach` を活用)、
  `file_put_contents()`(`FILE_APPEND` は付けずに上書き)で
  `$path` に書き込みます。書き込んだあとにもう一度 `loadConfig()` で
  読み直し、元の連想配列と同じ内容になっているかを比較して
  表示するところまで実装できると、ファイルの読み書きを一通り
  体験したことになります。
