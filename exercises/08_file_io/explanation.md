# 解説: ファイル読み書き

## コードの流れ

`answer.php` は大きく7つのパートに分かれています。

1. **パスの準備**
   `__DIR__` を使って `config.txt` と `app.log` の絶対パスを
   組み立てています。相対パスに頼らないことで、どのディレクトリから
   実行しても同じ結果になるようにしています。

2. **`loadConfig()` 関数の定義**
   `file_exists()` で存在確認をしたあと、`file()` 関数でファイルを
   1行ずつの配列として読み込み、`explode("=", $line, 2)` で
   各行をキーと値に分割して連想配列 `$config` に詰め込んでいます。

3. **`writeLog()` 関数の定義**
   `date('Y-m-d H:i:s')` で現在日時の文字列を作り、渡された
   メッセージと組み合わせて、`file_put_contents()` の第3引数に
   `FILE_APPEND` を指定して `app.log` に追記しています。

4. **`file_exists()` による存在確認の実演**
   `config.txt` が実際に存在することを確認し、結果を表示しています。

5. **`loadConfig()` の呼び出しと結果の利用**
   `loadConfig($configPath)` を呼び出して連想配列を受け取り、
   `foreach` で中身を表示したあと、`$config['host']` のように
   キーを指定して値を取り出し、接続先の情報として表示しています。

6. **`fopen`/`fgets`/`fclose` による低レベルな読み込みの実演**
   `fopen($configPath, 'r')` でファイルを開き、`while (!feof($handle))`
   のループの中で `fgets($handle)` を使って1行ずつ読み込み、
   最後に `fclose($handle)` で確実に閉じています。

7. **`file_get_contents()` による一括読み込みと `writeLog()` の実行**
   `file_get_contents($configPath)` でファイル全体を1つの文字列として
   読み込んで表示したあと、`writeLog()` を2回呼び出してログを追記し、
   最後に `app.log` の中身を表示して、追記が効いていることを
   確認できるようにしています。

全体を通して、「同じ『ファイルを読み込む』という目的を、
低レベルな方法(`fopen`/`fgets`/`fclose`)と手軽な方法
(`file()`、`file_get_contents()`)の両方で体験し、実務でよく使う
『設定ファイルの読み込み』『ログの追記』という2つの定番パターンを
自分の手で実装する」という構成になっています。

## 重要なポイント(使用した関数・構文の解説)

- **`file_exists(パス)`**
  指定したパスにファイル(またはディレクトリ)が存在するかどうかを
  `true`/`false` で返す関数です。存在しないファイルに対して
  `fopen()` や `file()` を呼び出すと警告(Warning)が発生するため、
  「まず存在確認をしてから処理する」という順序を守ることが大切です。

- **`file(パス, フラグ)`**
  ファイルの中身を「1行ごとの要素を持つ配列」として、まるごと
  読み込む関数です。`FILE_IGNORE_NEW_LINES` を指定すると各行末の
  改行コードを自動的に取り除き、`FILE_SKIP_EMPTY_LINES` を指定すると
  空行を結果に含めないようにできます。内部で自動的にファイルを
  閉じてくれるため、`fclose()` を呼び出す必要はありません。

- **`fopen(パス, モード)` / `fgets($handle)` / `feof($handle)` / `fclose($handle)`**
  ファイルをより細かく制御しながら操作するための、低レベルな
  関数群です。
  - `fopen()` はファイルを開き、以降の操作に使う「ファイルハンドル」
    を返します。モードには `'r'`(読み込み専用)、`'w'`(書き込み用、
    既存の内容は消える)、`'a'`(追記用)などがあります。
  - `fgets($handle)` は、現在の読み込み位置から改行までの1行分を
    読み込みます。
  - `feof($handle)` は、読み込み位置がファイルの末尾に達したかどうかを
    判定します。`while (!feof($handle)) { ... }` という書き方で
    「ファイルの終わりまで繰り返す」ループがよく使われます。
  - `fclose($handle)` は、開いたファイルを閉じます。**開いたら
    必ず閉じる**のが鉄則です。

- **`file_get_contents(パス)`**
  ファイルの中身をまるごと1つの文字列として読み込む関数です。
  内部的には `fopen` → 読み込み → `fclose` という流れをすべて
  代わりにやってくれるため、`fclose()` を自分で呼ぶ必要はありません。
  小さめの設定ファイルやテキストファイルを手軽に読みたいときに
  非常によく使われます。

- **`file_put_contents(パス, データ, フラグ)`**
  文字列をファイルに書き込む関数です。第3引数に何も指定しないと、
  呼び出すたびにファイルの中身が新しい内容で「上書き」されます。
  第3引数に `FILE_APPEND` を指定すると、既存の内容を消さずに
  「末尾に追記」するようになります。ログのように「過去の内容を
  残しつつ、新しい内容を積み重ねたい」場合には `FILE_APPEND` が
  欠かせません。

- **`explode(区切り文字, 文字列, 上限数)`**
  文字列を指定した区切り文字で分割する関数です。第3引数に数値を
  指定すると、「その数までしか分割しない」という上限を設定できます。
  `explode('=', $line, 2)` とすることで、「最初の `=` のところで
  1回だけ分割する」という動きになり、値の中に `=` が含まれていても
  キーと値の2つに正しく分けることができます。

- **`__DIR__`**
  実行中のPHPファイル自身が置かれているディレクトリの絶対パスを
  返す、マジック定数と呼ばれる特別な定数です。`__DIR__ . '/config.txt'`
  のように使うことで、実行時のカレントディレクトリに左右されない
  安全なパスを組み立てられます。

- **`??`(null合体演算子)**
  `$config['host'] ?? '不明'` のように書くと、「`$config['host']` が
  存在してかつ `null` でなければその値を、そうでなければ `'不明'` を
  使う」という意味になります。配列にキーが存在するか分からないときの
  デフォルト値指定によく使われます。

## 初心者がつまずきやすいポイント

- **`fclose()` を呼び忘れる**
  `fopen()` で開いたファイルは、処理が終わったら必ず `fclose()` を
  呼んで閉じる必要があります。閉じ忘れても小さなスクリプトでは
  すぐに問題が表面化しないことがありますが、長時間動き続ける
  プログラムや、同じファイルを大量に開閉するプログラムでは、
  「開いているファイルの数」がシステムの上限に達してしまうなどの
  不具合の原因になります。

- **`FILE_APPEND` を付け忘れて、ログが毎回消えてしまう**
  `file_put_contents($path, $data)` のように第3引数を省略すると、
  デフォルトでは「上書きモード」になります。ログのつもりで
  実装していたのに、実行するたびに1行しか残らない…という場合は、
  `FILE_APPEND` の指定を忘れていないか確認してみましょう。

- **相対パスを使ってしまい、実行場所によって動作が変わる**
  `"config.txt"` のように書いてしまうと、`php answer.php` を
  `exercises/08_file_io` の中で実行したときは動いても、
  リポジトリのルートから `php exercises/08_file_io/answer.php` の
  ように実行すると「ファイルが見つからない」というエラーになって
  しまいます。`__DIR__` を使うと、この問題を避けられます。

- **行末の改行コードを取り除き忘れる**
  `fgets()` や、フラグを指定しない `file()` で読み込んだ行には、
  末尾に改行コード(`\n` や `\r\n`)が残っていることがあります。
  これを取り除かずに `explode("=", $line)` で分割すると、値の末尾に
  見えない改行が混ざり込み、比較や表示のときに意図しない挙動を
  引き起こすことがあります。`trim()` を使うか、`file()` に
  `FILE_IGNORE_NEW_LINES` を指定して対処しましょう。

- **存在しないファイルをいきなり開こうとする**
  `file_exists()` で確認せずに `fopen()` や `file()` を呼び出すと、
  ファイルが存在しない場合に警告(Warning)が表示されます。
  警告が出てもプログラム自体は止まらないことが多いですが、
  「なぜか設定が空っぽになる」といった分かりにくい不具合の原因に
  なるため、事前の存在確認を習慣にしましょう。

## よくあるエラーと対処法

- **`Warning: file_get_contents(...): Failed to open stream: No such file or directory`**
  指定したパスにファイルが存在しないときに発生します。
  `config.txt` を削除してしまった場合や、`__DIR__` を使わずに
  相対パスを書いていて別のディレクトリから実行した場合などに
  起こりやすいので、パスの組み立て方を確認しましょう。
  `file_exists()` で事前にチェックしておくと、警告の代わりに
  分かりやすいメッセージを自分で表示できます。

- **`Warning: fopen(...): Failed to open stream: Permission denied`**
  ファイルやディレクトリへの書き込み・読み込み権限がない場合に
  発生します。`app.log` を作成・追記しようとしているディレクトリの
  権限を確認してみましょう(演習用のディレクトリであれば、通常は
  問題なく書き込めるはずです)。

- **`Fatal error: Uncaught TypeError: loadConfig(): Argument #1 ($path) must be of type string, null given`**
  関数の引数に想定と異なる型(この場合は `null`)を渡してしまった
  ときに発生します。`loadConfig()` の戻り値の型を `array` と
  宣言しているように、引数にも `string` という型を指定しているため、
  呼び出し側で変数の中身が正しく設定されているか確認しましょう。

- **`app.log` の中身が思ったより増えていない/毎回1行しかない**
  エラーメッセージは出ないものの意図した動作にならないパターンです。
  `file_put_contents()` の第3引数に `FILE_APPEND` を指定しているか、
  もう一度コードを見直してみましょう。

- **設定を読み込んでも `$config['host']` が空になる**
  `config.txt` の行末に余計な空白や改行が残っていたり、
  `explode('=', $line, 2)` の第3引数(上限数)を指定し忘れて
  値の中の `=` でさらに分割されてしまっていたりする可能性があります。
  `var_dump($config)` を使って連想配列の中身を確認すると、
  原因を特定しやすくなります。

## まとめ

この演習では、PHPでファイルを読み書きするための代表的な方法を
一通り体験しました。

- `fopen`/`fgets`/`fclose` を使うと、ファイルを1行ずつ細かく
  制御しながら読み込むことができます。開いたら必ず `fclose()` で
  閉じることを忘れないようにしましょう。
- `file()` や `file_get_contents()` を使うと、少ないコードで
  手軽にファイルの中身を読み込むことができます。内部で自動的に
  ファイルを閉じてくれるため、`fclose()` は不要です。
- `file_put_contents()` に `FILE_APPEND` を指定すると、ファイルに
  内容を「追記」できます。指定を忘れると、実行するたびに中身が
  上書きされてしまう点に注意しましょう。
- `file_exists()` で事前に存在確認をしてから処理を行うことで、
  分かりにくい警告やエラーを未然に防ぐことができます。
- key=value 形式の設定ファイルを読み込んで連想配列に変換する
  `loadConfig()` のような処理や、`writeLog()` のような簡易ロガーは、
  実際のサーバー運用スクリプトでも非常によく使われる基本パターンです。
  ここで学んだ考え方は、より本格的な設定管理やログ管理の仕組みを
  理解するための土台になります。
