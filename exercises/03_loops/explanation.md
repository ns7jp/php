# 解説: 繰り返し処理

## コードの流れ

`answer.php` は大きく4つのパートに分かれています。

1. **準備運動: for・while・do-whileの比較**
   同じ「1から5まで出力する」処理を `for` / `while` / `do-while` の3通りで書き、
   結果が同じになることを確認しています。さらに「最初から条件を満たさない」
   ケースを使って、`while` は1回も実行されないのに対し、`do-while` は
   条件に関係なく必ず1回は実行される、という違いを見せています。

2. **FizzBuzz(for文)**
   1から100までの数字を `for` 文で1つずつ処理し、`if` / `elseif` / `else` と
   組み合わせて、3の倍数・5の倍数・両方の倍数・それ以外を判定しています。
   「15の倍数の判定を一番先に書く」のがポイントです。

3. **サーバー一覧からwebサーバーだけ接続確認(foreach + continue)**
   `$servers` 配列を `foreach` で順番に処理し、`str_contains()` で
   サーバー名に `"web"` が含まれているかを判定します。
   含まれていない場合は `continue` でその回の処理をスキップし、
   含まれている場合だけ接続確認中のメッセージを出力しています。

4. **二重ループで再現するヘルスチェックのリトライ処理**
   `$healthCheckResults` という「サーバー名 => 5回分の結果の配列」という
   構造のデータを使い、外側の `foreach` でサーバーごとに、
   内側の `while` で1回目〜5回目のチェック結果を順番に確認しています。
   連続失敗回数が3に達したら `break` で内側のループだけを打ち切り、
   外側のループ(次のサーバーの処理)はそのまま継続しています。

全体を通して、「同じような繰り返し処理でも、状況に応じて `for`・`while`・
`foreach` を使い分ける」という考え方を体験できる構成になっています。

## 重要なポイント(使用した関数・構文の解説)

- **`for` 文**
  `for (初期化; 条件; 更新) { ... }` という形で書きます。
  「繰り返す回数や範囲があらかじめはっきり決まっている」処理
  (例: 「1から100まで」)に向いています。

- **`while` 文**
  `while (条件) { ... }` という形で書きます。
  ループに入る前に毎回条件をチェックし、条件が `true` の間だけ処理を繰り返します。
  条件が最初から `false` であれば、中身は一度も実行されません。
  「何回繰り返すか事前には決まっていないが、ある条件を満たすまで続けたい」
  処理に向いています。

- **`do-while` 文**
  `do { ... } while (条件);` という形で書きます。
  `while` 文とほぼ同じですが、条件のチェックが「後」に来るのが特徴です。
  そのため、条件の真偽にかかわらず、中身が **必ず最低1回は実行される** という
  性質があります。「とりあえず1回は必ず試したい」処理に向いています。

- **`foreach` 文**
  `foreach ($配列 as $値) { ... }` または
  `foreach ($配列 as $キー => $値) { ... }` という形で書きます。
  配列の先頭から末尾まで、要素を順番に1つずつ取り出して処理するための構文です。
  `for` 文のように添字(インデックス)を自分で管理する必要がないため、
  配列を処理する場合はほとんどのケースで `foreach` の方が読みやすく書けます。

- **`break`**
  ループの実行中に `break` に到達すると、そのループ自体をそこで終了します。
  二重ループの場合、`break` は「自分が書かれている、いちばん内側のループ」
  だけを終了させ、外側のループには影響しません。

- **`continue`**
  ループの実行中に `continue` に到達すると、そのループの「今回の分」の
  残りの処理を飛ばし、次の繰り返し(次の要素・次のカウント)に進みます。
  `break` と違って、ループ自体は終了しません。

- **剰余演算子 `%`**
  割り算の余りを求める演算子です。`$number % 3 === 0` は
  「3で割った余りが0」、つまり「3の倍数である」ことを表します。
  FizzBuzzのような「◯の倍数かどうか」の判定でよく使われます。

- **`str_contains($haystack, $needle)`**
  `$haystack`(対象の文字列)の中に `$needle`(探したい文字列)が
  含まれているかどうかを `true`/`false` で返す関数です(PHP8.0以降)。
  「サーバー名に特定の文字列が含まれているか」のような判定に便利です。

## 初心者がつまずきやすいポイント

- **`while` の更新処理を書き忘れて無限ループになる**
  `while` 文は `for` 文と違い、カウンターの更新(`$i++` など)を
  自分でループの中に書かなければいけません。書き忘れると条件がずっと
  `true` のままになり、プログラムが終わらない「無限ループ」になってしまいます。
  `while` を書くときは、必ず「条件に使っている変数がループの中で
  ちゃんと変化しているか」を確認しましょう。

- **`break` と `continue` を混同する**
  どちらも「繰り返しの流れを変える」構文ですが、働きは大きく違います。
  `break` は繰り返し自体を終わらせ、`continue` はその回の残りだけを
  スキップして次に進みます。「もうこれ以上繰り返さなくていい」のか
  「今回だけスキップしたいだけ」なのかを意識して使い分けましょう。

- **二重ループでの `break` が及ぶ範囲を誤解する**
  内側のループで `break` を使っても、外側のループは止まりません。
  「1つのサーバーのチェックを打ち切る」つもりが「全サーバーのチェックを
  やめてしまう」といった勘違いをしないよう注意しましょう。
  もし外側のループごと止めたい場合は、`break 2;` のように
  抜けたいループの数を指定する書き方があります(発展課題で紹介しています)。

- **FizzBuzzで判定の順番を間違える**
  「3の倍数かどうか」を先にチェックしてしまうと、15(=3の倍数でもあり
  5の倍数でもある数)が `"FizzBuzz"` ではなく `"Fizz"` と判定されてしまいます。
  「両方の条件を満たすケース(15の倍数)」を必ず一番先にチェックするのが
  ポイントです。

- **配列の添字が0から始まることを忘れる**
  `$results[0]` が「1回目」のチェック結果に対応します。
  「◯回目」という人間にとって自然な数え方(1から)と、
  配列の添字(0から)がズレることに注意しましょう。
  この演習では `$results[$attempt - 1]` のように、
  1から数えた `$attempt` から1を引くことでズレを調整しています。

## よくあるエラーと対処法

- **プログラムが終わらない(無限ループ)**
  `while` や `do-while` で、条件に使っている変数を更新し忘れると発生します。
  実行中にターミナルで `Ctrl + C` を押すと強制終了できます。
  ループの中で条件に関わる変数がちゃんと変化しているか見直しましょう。

- **`Parse error: syntax error, unexpected...`**
  `for`・`while`・`foreach` の括弧 `()` や波括弧 `{}` の対応が
  取れていないときによく出ます。開き括弧と閉じ括弧の数が
  一致しているか、1つずつ数えて確認しましょう。

- **`Call to undefined function str_contains()`**
  `str_contains()` はPHP8.0以降で追加された関数です。
  それより古いバージョンのPHPで実行すると、この関数自体が
  存在せずエラーになります。古い環境では、代わりに
  `strpos($haystack, $needle) !== false` という書き方で
  同じ判定ができます。

- **期待した回数より少ない(多い)回数しか繰り返されない**
  `for` 文の条件を `<=` にすべきところを `<` にしてしまう
  (あるいはその逆)といったミスでよく起こります。
  「1から100まで」なら `$i <= 100`、「0から99まで」なら `$i < 100` のように、
  範囲の端(境界値)を意識して条件を書きましょう。

- **`Warning: Undefined array key ...`**
  配列に存在しない添字・キーへアクセスするとこの警告が出ます。
  ヘルスチェックの例で言えば、`$attempt` の数え方や `-1` の位置を
  間違えると発生しやすいので、添字がずれていないか確認しましょう。

## まとめ

- `for` は繰り返す回数がはっきり決まっているとき、`while` は条件を
  満たす間ずっと繰り返したいとき、`do-while` は「最低1回は必ず実行したい」
  ときに向いています。目的に応じて使い分けましょう。
- `foreach` は配列の中身を順番に処理するのにもっとも適した構文です。
  添字を自分で管理する必要がなく、コードもシンプルになります。
- `break` はループそのものを終了させ、`continue` はその回だけをスキップして
  次に進みます。二重ループでは、`break`/`continue` が「どのループに効くのか」
  (基本的には自分が書かれているいちばん内側のループ)を常に意識しましょう。
- 今回学んだ「一覧をひとつずつ処理する(バッチ処理)」「失敗したら
  一定回数までリトライして諦める(リトライ処理)」という考え方は、
  サーバー構築・運用の現場で日常的に使われている、非常に実践的なパターンです。
