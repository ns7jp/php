# PHP基礎演習パック 〜サーバー構築エンジニアを目指すポートフォリオ〜

未経験からサーバー構築エンジニア(インフラエンジニア)への転職を目指す学習者のために作成した、
**PHP基礎演習パック**です。プログラミング未経験・初心者でも、順番に進めるだけで
「変数」から「オブジェクト指向」「サーバー情報の取得」「ログ解析」まで、実務で使う基礎力を
段階的に身につけられるように設計しています。

最終的には、これらの演習で学んだ内容をすべて統合した**「サーバー監視ダッシュボード」**という
ミニアプリケーションを完成させ、ポートフォリオの成果物とします。

## このリポジトリについて

サーバー構築エンジニアの求人では、Linuxやネットワークの知識に加えて
「簡単なスクリプトが書けること」「サーバーのログを読んで問題を切り分けられること」
「設定ファイルやデータの形式(JSON/CSVなど)を理解していること」が求められる場面が多くあります。

このリポジトリは、そうした実務に近い題材(サーバーの死活監視、ログ解析、設定ファイル読み込みなど)を
あえて練習問題のテーマに選ぶことで、「ただの言語学習」で終わらせず、
**サーバー運用の現場で役に立つ形でPHPの基礎を身につける**ことを目的にしています。

## 対象読者

- プログラミング未経験・初心者で、これからサーバー構築エンジニアを目指す人
- 独学でPHPを一通り学びたいが、何を作ればよいか分からない人
- ポートフォリオとして「学習の過程と成果」の両方を採用担当者に示したい人

## 全体構成

```
php/
├── README.md                        … このファイル(全体像の説明)
├── docs/
│   ├── 00_setup.md                  … 環境構築ガイド
│   └── 01_roadmap.md                … 詳細な学習ロードマップ・チェックリスト
├── exercises/                       … 演習本体(01〜16、番号順にステップアップ)
│   ├── 01_variables_datatypes/      … 演習ごとに README / practice.php / answer.php / explanation.md
│   ├── 02_operators_conditionals/
│   ├── ...
│   └── 16_log_analyzer/
└── capstone/
    └── server_monitor_dashboard/    … 集大成:サーバー監視ダッシュボード(CLIアプリ)
```

各演習フォルダは、必ず次の4つのファイルで構成されています。

| ファイル | 役割 |
| --- | --- |
| `README.md` | 学習目標・演習の要件・実行方法・ヒント・実務との関連をまとめた「問題文」 |
| `practice.php` | 自分で穴埋めしながら実装する、未完成のひな形コード |
| `answer.php` | 実際に動作する模範解答(`php answer.php`で実行できます) |
| `explanation.md` | コードの流れ・重要なポイント・つまずきやすい点を解説した「解答解説」 |

## 環境構築

PHPさえ入っていれば、Webサーバーやデータベースサーバーなしで、すべてコマンドラインだけで
動作確認ができます。インストール手順は [docs/00_setup.md](./docs/00_setup.md) を参照してください。

```bash
# バージョン確認(PHP 8.0以上推奨)
php -v

# 演習01の模範解答を実行してみる
php exercises/01_variables_datatypes/answer.php
```

## 学習の進め方

1. `docs/01_roadmap.md` を見て、今日取り組む演習を1つ選ぶ(基本は番号順でOK)
2. その演習フォルダの `README.md` を読み、要件とヒントを確認する
3. `practice.php` を自分で開き、`// TODO:` と書かれた箇所を実装する
   (`php practice.php` で動作確認しながら進められます)
4. 実装できたら `php -l practice.php` で構文チェック、`php practice.php` で実行確認をする
5. `answer.php` と見比べて、自分の実装との違いを確認する
6. `explanation.md` を読み、「なぜそう書くのか」「初心者がつまずきやすい点」まで理解する
7. 余裕があれば、README.md末尾の「発展課題」にも挑戦する

詳しい学習ロードマップ(ステージ分け・前提知識・チェックリスト)は
[docs/01_roadmap.md](./docs/01_roadmap.md) にまとめています。

## 集大成プロジェクト:サーバー監視ダッシュボード

[capstone/server_monitor_dashboard/](./capstone/server_monitor_dashboard/) は、上記16演習の
集大成として作成した、CLIで動く「サーバー監視ダッシュボード」です。監視対象サーバー一覧の管理、
実行環境情報の取得、アクセスログの集計、例外処理によるエラーハンドリングまでを1つのアプリケーションに
統合しています。ポートフォリオとして人に見せるときは、まずこのプロジェクトから紹介することをおすすめします。

```bash
php capstone/server_monitor_dashboard/dashboard.php
```

## このポートフォリオが示すスキル

- **PHPの基礎文法**(変数・条件分岐・ループ・配列・関数)を一通り扱える
- **データ形式の実務的な取り扱い**(ファイルI/O、CSV、JSON、正規表現によるログ解析)
- **Webアプリケーションの基本要素**(フォームバリデーション、セッション管理、DB連携)への理解
- **オブジェクト指向設計**の基礎(クラス、継承、カプセル化)
- **セキュリティを意識したコーディング**(XSS対策・SQLインジェクション対策・コマンドインジェクションへの注意)
- **本番運用を意識した設計**(例外処理、エラーログの分離、設定ファイルの外部化)
- **サーバーの状態を可視化するスクリプトが書ける**(ディスク・負荷・メモリの取得、ログ集計)

## このリポジトリの先にあるもの

このリポジトリはPHPというプログラミング言語の基礎を通じて「読み書きできるコード」を身につける
ための教材ですが、サーバー構築エンジニアとしての学習はここがゴールではありません。
今後は、Linuxコマンド操作、Webサーバー(Apache/Nginx)の構築・設定、ネットワークの基礎、
クラウド(AWSなど)でのサーバー構築、シェルスクリプトによる自動化といった領域へ学習を広げていく
予定です。このリポジトリは、その土台となる「プログラムを書いて動かす力」を証明するものです。
