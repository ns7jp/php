# 学習ロードマップ

このリポジトリの16演習は、**やさしい順から難しい順へ**並んでいます。
基本的には番号順(01→16)に進めることをおすすめしますが、興味のあるテーマから
つまみ食いしても問題ないように、各演習の「前提知識」に必要な演習番号を明記しています。

ペース配分の目安としては、**平日に1日1本ずつ進めれば、およそ3〜4週間で完走できる**ボリュームです。
急ぐ必要はありません。`answer.php`を写経するだけで終わらせず、`explanation.md`まで読んで
「なぜそう書くのか」を理解することを優先してください。

## 全体マップ

```
ステージ1: PHPの文法基礎 (演習01〜05)
   │  変数 → 条件分岐 → 繰り返し → 配列 → 関数
   ▼
ステージ2: データの扱い方 (演習06〜09)
   │  文字列 → 日付・時刻 → ファイルI/O → CSV・JSON
   ▼
ステージ3: Webアプリケーションの基礎 (演習10〜12)
   │  フォーム・バリデーション → セッション・Cookie → データベース(PDO)
   ▼
ステージ4: 実務レベルの設計・運用視点 (演習13〜16)
   │  オブジェクト指向 → 例外処理・ログ → サーバー情報取得 → ログ解析
   ▼
集大成: capstone/server_monitor_dashboard/
      これまで学んだ全部を統合した「サーバー監視ダッシュボード」を組み立てる
```

## なぜこの順番なのか

- **01〜05(文法基礎)** は、PHPに限らずプログラミング全般の土台になる部分です。ここが曖昧なまま
  先に進むと、あとの演習でつまずく原因になるため、最初にしっかり固めます。
- **06〜09(データの扱い方)** では、文字列・日付・ファイル・JSONといった「サーバーが日々扱うデータ」
  を処理する力を身につけます。ログ解析(16)や設定ファイル管理につながる重要なステージです。
- **10〜12(Webアプリケーションの基礎)** では、ユーザーからの入力(フォーム)を安全に扱う方法、
  状態を保持する仕組み(セッション)、データベースとの連携という、Webシステムの三本柱を学びます。
- **13〜16(実務レベルの設計・運用視点)** は、単に「動くコード」から一歩進んで、
  「壊れにくい・読みやすい・運用しやすいコード」を書くための考え方です。特に15・16は、
  サーバー構築エンジニアの実務に直結するテーマとして設計しています。
- **capstone** は、16本の演習で身につけた技術を実際に組み合わせて1つのアプリケーションに
  する体験です。ポートフォリオとして人に見せるときは、まずこのcapstoneから紹介するのがおすすめです。
